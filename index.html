DASHBOARD CONNECTION

Dashboard

Choose an account, select the clients it may access, and enter the spreadsheet URL for each selected client.

For a Regular Admin, check each client to reveal its URL field, then paste that client’s Google Sheets link. Each selected client must have its own URL.

Preview URLs are stored in this browser only; no spreadsheet data is fetched.

PRIVATE SHEET CONNECTION

Connect your PLANTILLA sheet

Open ERTH PORTAL from its GitHub Pages HTTPS address, not a local index.html file. Paste the Google Sheets URL. Public sheets connect directly; authorize Google for a private sheet.

The spreadsheet must include a tab named PLANTILLA. Do not publish employee data to the web.
